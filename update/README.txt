Frutiger Nano - DOOG unincorporated

1. Put FrutigerNano.exe anywhere (Desktop is fine) and double-click it.
2. If Windows blocks it: it isn't code-signed, so Smart App Control must be off
   (Windows Security > App & browser control > Smart App Control > Off).
   On SmartScreen's "Windows protected your PC" screen click More info > Run anyway.
3. Paste text in the Original box and press Rewrite (or Ctrl+Enter).
   Ctrl+Alt+N rewrites whatever you copied, from any app.
